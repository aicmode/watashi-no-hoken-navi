# わたしの保険ナビ

保険に興味がない人でも「ちょっと見てみたい」と思える、体験型のWebプロトタイプです。

**「保険を、少し理解できる。」**
🚗 クルマ / 📱 スマートフォン / 🏠 住まい の中から**自分にしっくりくる例えを選び**、
その世界観に置き換えながら、暮らしの変化・今ある備え・備える方法を考える体験を提供します。

---

## 背景となった現場課題

保険営業の現場で働く方へのヒアリングから、次の課題が出発点になっています。

> 「新車の話題には興味を持ってもらえても、
> 新しい保険商品の話題には関心を持ってもらいにくい」

そこで、難しくなりがちな保険を **「身近なものの装備・備えを選ぶような感覚」** に置き換え、
分かりやすく・楽しく知ってもらうためのツールとして企画しました。

さらに「クルマに興味がない人には響かない」という課題に対して、
**ユーザー自身が自分に合う例えを選べる**形へ発展させています。

## MVPの目的

商品を売ることではなく、心理的ハードルを下げることだけに集中しています。

```
「保険に興味がない」
   ↓
「自分にも関係あるかも」
   ↓
「商品を選ぶ前に、自分の暮らしや今ある備えを考えてみたい」
   ↓
「担当者に相談してみようかな」
```

本リポジトリは、担当者へ見せてフィードバックをもらうための **MVPプロトタイプ** です。
実際の保険商品を販売するサイトではありません。

## 主な機能

| 画面 | 内容 |
| --- | --- |
| TOP (`/`) | メインコピー、共感、備えを考える理由、4STEP、保険の3分野、備えを考える3視点、保険以外の備え方、今ある備えの確認、6つの見直しタイミング、FAQ、CTA |
| 体験フロー **STEP1「たとえる」** (`/navi`) | 「あなたに合う例えを選んでみましょう」— 🚗 クルマ / 📱 スマートフォン / 🏠 住まい から1つ選択 |
| 体験フロー **STEP2「えらぶ」** | 「最近、あなたの暮らしで変わったことは？」を6つのライフイベントカードから1つ選択 |
| 体験フロー **STEP3「知る」** | **選んだ例え × 選んだライフイベント**に応じた解説と「この変化で考えてみたいこと」を表示。4つの備えカード、保険以外の備え方、かんたんナビへつなぐ |
| 体験フロー **STEP4「考える」** | ここまでで分かった3点を振り返り、「自分の場合について聞いてみる」相談CTAへつなぐ |
| 相談モーダル | 「プロトタイプのため、現在お問い合わせ機能は準備中です。」を表示 |

### 例え（3種）— 今回の追加機能

| 例え | 世界観のキーワード | 選択カードの説明 |
| --- | --- | --- |
| 🚗 クルマ | 安全装備 / メンテナンス / もしものトラブル | 安全装備を選ぶように |
| 📱 スマートフォン | ケース / パスコード / バックアップ / セキュリティ | バックアップやセキュリティのように |
| 🏠 住まい | 鍵 / 火災対策 / 防災 / 修繕 | 安心して暮らすための備えのように |

### ライフイベント（6種）

🚗 車を買った / 💍 結婚した / 👶 子どもができた / 🏠 家を買った / 💼 働き方が変わった / 🌱 将来について考え始めた

### 「例え × ライフイベント」＝ 18パターンの体験

3種類の例え × 6種類のライフイベント = **18パターン**それぞれに、専用の説明文を用意しています。
各パターンは次の4段階で構成されています。

1. **身近な例え** … 選んだ世界（クルマ／スマホ／住まい）の話
2. **暮らしへの橋渡し** … 同じ考え方が暮らしにもあること
3. **備えについて考えるきっかけ** … 締めの1文
4. **この変化で考えてみたいこと** … 自分の暮らしにつなげる3つの問い

例：「子どもができた」を選んだ場合

- 🚗 クルマ …「乗る人が増えると、求める装備も変わる」
- 📱 スマートフォン …「大切なデータが増えていく」
- 🏠 住まい …「家族が増えると、住まいも整え直す」

体験の途中で **「例えを変更する」／「暮らしの変化を選び直す」** から、いつでも入口を選び直せます。
例えだけを変えた場合は、選択済みのライフイベントを保ったまま STEP3 の説明が切り替わります。

### 「備え」の4カテゴリー

🏥 医療への備え / 💼 働けないときへの備え / 👨‍👩‍👧 家族への備え / 🚗 事故・トラブルへの備え

各カードの「○○に例えるなら」の文言も、選んだ例えに合わせて切り替わります。開いた詳細では「どんなことを考える？」という短い観点と、「こんなことを考えてみる」という問いを1つ表示します。

| 備え | 🚗 クルマ | 📱 スマートフォン | 🏠 住まい |
| --- | --- | --- | --- |
| 医療への備え | ぶつかったときに被害を小さくする装備 | 壊れたときのための保護ケースと修理サポート | もしものときのための防災設備 |
| 働けないときへの備え | 走れなくなったときのロードサービス | 使えない間をしのぐ代替手段 | 停電に備えた予備の電源や蓄え |
| 家族への備え | 同乗者を守るためのエアバッグ | 大切なデータを残しておくバックアップ | 家族みんなに知らせる火災警報器 |
| 事故・トラブルへの備え | ぶつからないための予防安全装備 | 紛失や不正利用を防ぐパスコード | 玄関の鍵と戸締まりの習慣 |

## 初心者向け教育コンテンツ

商品を紹介する前に、次の順で理解できるようにしています。

1. 病気やケガ、事故、働き方・家族・住まいの変化などを「備えを考える理由」として知る
2. 「起きる可能性」「生活への影響」「何で準備するか」の3つの視点で整理する
3. 貯蓄、公的な制度、勤務先の制度、民間の保険という複数の備え方を知る
4. 今の貯蓄・福利厚生・公的な制度・加入済みの保障・家族の状況・生活費を確認する

すべてを保険で備える前提にはせず、自分にすでにある備えと足りない部分を確認する構成です。具体的な制度名、支給額、税金、適用条件には踏み込みません。

TOP下部のミニFAQでは、次の疑問をアコーディオンで扱います。

- 保険は全員に必要なのか
- 若いうちは考えなくてもよいのか
- 保険は多いほど安心なのか
- 何から確認したらよいのか
- このサイトだけで契約を決められるのか

## 技術スタック

- Next.js 16（App Router）
- React 19
- TypeScript
- Tailwind CSS v4
- 追加の依存ライブラリなし（アニメーションはCSSのみ）

バックエンド・DB・ログイン・外部APIは使用していません。全ページが静的に生成されます。

## ローカル起動方法

```bash
npm install
npm run dev      # http://localhost:3000
```

その他のコマンド:

```bash
npm run build      # 本番ビルド
npm run start      # 本番ビルドの起動
npm run lint       # ESLint
npm run typecheck  # tsc --noEmit
```

Node.js 20 以上を想定しています。

## Vercelへのデプロイ

環境変数なしでそのままデプロイできます。リポジトリをVercelにインポートするだけで、
フレームワークプリセット（Next.js）が自動検出され、`npm run build` でビルドされます。

### 拡張しやすくしてある箇所

- **相談導線**: `src/lib/contact.ts` の `href` を埋めるだけで、モーダル内の項目が実リンクとして動作します（UI側の変更は不要）。LINE・電話・問い合わせフォームへの差し替えを想定。
- **コンテンツ**: ライフイベント・備えカテゴリー・FAQ・教育コンテンツは `src/data/` の配列を編集して更新できます。
- **例えの追加**: `src/data/analogies.ts` の `ANALOGIES` に1件足すだけで、4種類目・5種類目（✈️ 旅行 / 🎮 ゲーム / ⚽ スポーツ など）を追加できます。UI 側（選択カード・比喩パネル・備えカード・TOPのチップ）はすべてデータ駆動なので、変更は不要です。型定義（`Record<LifeEventId, AnalogyStory>` / `Record<CoverageId, string>`）により、文章の書き忘れはビルド時に検出されます。
- **今後の発展余地**: 情報提供コンテンツ、税務・社会保障、資産運用、担当者紹介ページ、顧客管理、LINE連携、AI問い合わせ対応などを、ページ単位で追加できる構成にしています（本MVPでは未実装）。

## 実在の商品を扱わないプロトタイプであること

本サイトは保険について考えるきっかけを提供する**教育用デモプロトタイプ**です。
表示内容は一般的な情報であり、**特定の商品・契約を推奨するものではありません**。

- 実在する保険会社名・保険商品名は使用していません
- 保険料の表示、保険料シミュレーションは行いません
- 特定商品の契約推奨、投資助言は行いません
- 法律・税務・社会保障についての個別・断定的な助言は行いません
- 個人情報の入力フォーム・収集・送信は一切ありません（選択内容はブラウザ内でのみ保持され、リロードすると消えます）
- 加入を断定する表現は使わず、「暮らしに関係する備え」「考えてみる」という情報提供寄りの言い回しに統一しています
- 調査根拠があるように受け取られる一般化や割合表現は使用していません
- 保険の分野紹介は「生命保険 / 損害保険 / 医療・傷害など」の3分類にとどめ、「この会社はこれだけ」と断定しない構成にしています
